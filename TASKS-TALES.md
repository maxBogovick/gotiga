# Небылицы — комната рассказов

Комната для маленьких рассказов о работах. Не блог и не лента.
Правило комнаты: **каждая вещь в доме что-то помнит; здесь это записано**.

Адрес: `/tales` (полка) и `/tales/[slug]` (лист).
Название: RU «Небылицы», EN «Tall tales».

## 0. Принятые решения

| Вопрос | Решение |
|---|---|
| Хранение | `gazette_leaves` с `kind = 'tale'`. Новой таблицы нет. |
| Газета | Рассказы остаются видимыми и в вестнике. Газета сообщает — полка хранит. |
| Работа | Ровно одна, существующее поле `figurine_id`. |
| Порядок | Руками, перетаскиванием. Новое поле `shelf_order`. |

Всё остальное в схеме уже есть: двуязычные `title/dek/body` (до 12 000 знаков),
слаг, картинки, черновик/расписание/публикация/архив, RSS, «слежка», связь с работой.

## 1. Данные

Одна миграция — `src-tauri/server/migrations/20260824000000_gazette_shelf_order.sql`:

```sql
-- Порядок на полке небылиц. NULL = не расставлено: такие листы падают
-- в конец полки и сортируются по дате, как в вестнике.
ALTER TABLE gazette_leaves ADD COLUMN IF NOT EXISTS shelf_order INTEGER;

CREATE INDEX IF NOT EXISTS gazette_leaves_shelf_idx
    ON gazette_leaves (shelf_order NULLS LAST,
                       COALESCE(published_at, scheduled_at, created_at) DESC)
    WHERE kind = 'tale' AND status IN ('published', 'scheduled');
```

`kind = 'tale'` уже разрешён CHECK-ограничением исходной миграции — трогать его не нужно.

## 2. Сервер

**`src/models/mod.rs`** — `shelf_order: Option<i32>` в `GazetteLeafListed` и в `GazetteLeafDto`.
В `SaveGazetteLeafRequest` поле НЕ добавляем: порядок задаётся отдельной ручкой,
иначе drag'n'drop будет дёргать полное сохранение листа.

**`src/db/mod.rs`** (рядом с `list_gazette_leaves_public`, ~5353):

- `list_tales_public(limit) -> Vec<GazetteLeafListed>`
  `GAZETTE_LEAF_SELECT` + `WHERE l.kind = 'tale' AND (published | scheduled ≤ NOW())`
  `ORDER BY l.shelf_order NULLS LAST, COALESCE(...) DESC, l.id DESC`.
  Без пагинации — полка целиком, лимит 500 (`gazette::SHELF_TALES`).
  `pinned` в сортировку полки НЕ входит, в отличие от вестника: на полке,
  расставленной руками, он дрался бы с перетаскиванием. `pinned` только помечает
  рассказ, который комната показывает крупно, — лид выбирает фронтенд.
- `set_tale_shelf_order(&[(Uuid, i32)])` — один `UPDATE ... FROM (VALUES ...)` в транзакции.
- `gazette_leaf_neighbors` (~5726) — развилка по виду: для `kind = 'tale'` соседи ищутся
  среди небылиц по `shelf_order`, а не по всей газете. Иначе «рядом на полке»
  приведёт читателя в анонс показа.

**`src/services/mod.rs`** (~6466): `list_tales_public()`, `admin_reorder_tales(Vec<Uuid>)`
(индекс в массиве = `shelf_order`).

**`src/api/handlers.rs`**: `list_tales`, `admin_reorder_tales`.
**`src/api/mod.rs`**:
- `.route("/tales", get(handlers::list_tales))` — рядом со строкой 178;
- `.route("/admin/gazette/tales/order", post(handlers::admin_reorder_tales))` под админским слоем (~512).

## 4. `src/lib/gazette.ts` — одна правка, много следствий

`leafHref()` (строка 447) возвращает `/tales/${slug}` при `leaf.kind === 'tale'`.
После этого вестник, главная и страница работы начинают вести в комнату сами,
без правок в каждом компоненте.

`/gazette/[slug]/+page.ts` при `kind === 'tale'` делает `redirect(308, '/tales/' + slug)` —
старые ссылки не ломаются, каноничный адрес один.

Новый `src/lib/tales.ts`:

```ts
renderTale(body: string): TaleBlock[]   // абзацы по \n\n; строка '✦' → орнамент
```

Никакого markdown и никакого HTML в теле — значит, и sanitizer не нужен.

## 5. Комната `/tales`

`+page.ts` — `prerender = import.meta.env.VITE_BUILD_TARGET === 'web'`, как у остальных;
`load` зовёт `api.getTales()`.

- **Заглавие и одна строка правила**: «Каждая вещь здесь что-то помнит. Записано со слов.»
- **Лид** — закреплённый (`pinned`) рассказ крупной пластиной: заголовок, эпиграф, фото работы.
- **Полка корешков** — остальные. Узкие вертикальные карточки ~54px шириной,
  высота 260–340px, выведенная детерминированно из хеша слага: полка должна быть неровной.
  Заголовок вдоль корешка (`writing-mode: vertical-rl`), внизу узкая лента фотографии
  работы (`sepia(.4) contrast(.9)`, `opacity .5`) — вместо тиснения.
  Наведение и фокус: `translateY(-10px) rotate(-1deg)`, корешок выступает с полки.
  При `prefers-reduced-motion` — только смена тона, без сдвига.
- **«Открыть наугад»** — единственная навигация кроме полки. Ссылку выбираем в `onMount`,
  иначе prerender замурует один и тот же рассказ навсегда.
- Дат, счётчиков, пагинации, фильтров и «5 минут чтения» — нет. Это ускоряет
  восприятие, а комната устроена ради обратного.
- Корешкам НЕ давать `view-transition-name: figurine-{id}` — их на полке много,
  имена совпадут и переход отменится.

## 6. Лист `/tales/[slug]`

- Пергаментная колонка ~62ch, Fraunces/Georgia.
- Буквица: `::first-letter` первого абзаца — `float: left`, ~3.4em, цвет `--deep`.
- Разрыв абзацев — орнамент `✦`, а не пустая строка.
- **Работа на полях**: фотография ~150px в правом поле, `position: sticky; top: 12vh` —
  читаешь, а лицо смотрит на тебя. Уже `<1100px` уходит одной пластиной после первого абзаца.
- Фото получает `view-transition-name: figurine-{id}` — оно на листе одно,
  поэтому переход в `/figurines/[id]` морфится честно.
- Конец: «Эта вещь стоит здесь» → `figurineHref`, и «рядом на полке» (`leaf.prev/next`).
- Отметить — можно (как `GazetteMark`). Комментариев и кнопок «поделиться» — нет.

## 7. Админка: вкладка «Небылицы»

Новый `src/lib/components/admin/TalesPanel.svelte`.
В `src/routes/admin/+page.svelte` — пункт `['tales', 'adminTabTales']` в `TAB_GROUPS`
рядом с `gazette` (~121), ветка рендера (~779) и учёт в `layGazette` (~455):
seed с `kind: 'tale'` должен открывать вкладку `tales`, а не редакцию вестника.

Стол, а не форма:

- **Две панели.** Слева полка (список с перетаскиванием), справа стол.
- **Стол — это и есть бумага.** Ни одного подписанного поля ввода. Заголовок набирается
  той же гарнитурой и кеглем, какими выйдет; эпиграф — курсивом; тело — одна пергаментная
  область той же меры, что и опубликованная страница. Не «превью справа», а сама вещь.
- **Автосохранение** в черновик: debounce 2.5 с после последнего нажатия плюс `Cmd/Ctrl+S`.
  Статус при этом не меняется — черновик остаётся черновиком, опубликованное
  сохраняется опубликованным. Тихая строка «сохранено 12:04».
  Дубль в `localStorage` (`gotiga_tale_draft_${id}`), восстановление при открытии,
  если локальная версия новее `updatedAt`. Проза не теряется никогда.
- **Два языка**: переключатель RU/EN на месте плюс режим «оба» — две колонки
  с синхронной прокруткой для перевода.
- **Длина как тень**: рассказики маленькие. Под текстом волосяная линия, заполняющаяся
  к 2500 знакам; дальше тон уходит в медный. Числа нет.
- **`Cmd+Enter`** вставляет орнамент `✦` — чтобы не искать глиф.
- **Фокус-режим**: полка и хром прячутся, остаётся бумага. `Esc` возвращает.
- **Работа** прикалывается поиском по имени (как в `GazettePanel`), выбранная показывается
  фотографией ровно там, где окажется на странице, — в правом поле стола.
- **Порядок**: перетаскивание в левом списке, `adminReorderTales(ids)` через 600 мс после drop.
- **Статусы**: черновик / по расписанию / опубликовано / «на полку» (archived).
  Публикация — с восковой печатью, как в доме принято.
