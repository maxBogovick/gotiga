# Полка карт — прогресс

Чеклист работ из `BATTLE-SHELF-REVIEW.md`. Пункт не удалять: сделанное
вычёркивается `[x]`, не стирается. Порядок — по вреду для человека, который
берёт карту, а не по дешевизне правки.

Как вычёркивать: `- [ ]` → `- [x]`, в конце строки коротко что сделано и где,
если не очевидно из текста.

Связанный долг движка (способности не исполняются) остаётся в
`TASKS-BATTLE-DOLG.md` §1.2 — здесь только то, что полка и лист должны показать
честно, даже пока глаголы ещё не ходят.

## 1. Паспорт тела на самой карте

Один отрисовщик, `BattleCard.svelte`. Иначе полка, стол и сцена разъедутся.

- [x] В полосе `.numbers` кроме здоровья и маны: броня, оберег, дальность, шаг, лечение — `bodyPassport()`
- [x] Нулевые значения паспорта не печатать
- [x] Kind — одно слово из словаря (тело / заклинание / реликвия), не свободный `type` — `battlesKindUnit` и соседние
- [x] Канал удара — слово, если не умолчание «телесный»; иначе можно молчать — `channelLabelKey`
- [x] Кружки cost/power: `aria-label` со словом, не цифра одна
- [x] На corners кружки не `<button>`, пока это не стол хранителя: на полке это не ручки
- [x] Ключи i18n в `en.ts` и `ru.ts` (часть уже есть как `battleStatArmour` и дальше — не плодить вторые, если те же слова)

Слот полки 261 px, свойства 81–89 px, фут пустой 10 %, черты Creature 92→0,
Granny 33→0.

- [x] У `layout: corners` не резервировать пустой фут (`footShare` не ест место, кружки уже снаружи) — `.slot--flush-foot`

- [x] На миниатюре не печатать двуязычные скобки `(Вихрь Души)` — `.trait-other` скрыт на полке
- [x] `interactive={false}` на полке: наклон — церемонии получения, не каталогу

## 4. Честность прозы и данных

Полка врёт и тогда, когда геометрия идеальна.

- [x] `pricesOf` пушит только `amount > 0` (Granny больше не показывает «0 RAVEN FEED»)
- [x] Published с непустым `traits`, звучащим как правило, и пустым `abilities` — блок в `readiness` (`traitsWithoutAbilities`) и понижение прозы до лора без двоеточия (`printTraitRule`)
- [x] Published без одной строки эффекта на языке полки — блок `noEffect`; на лице эффект без `abilities` читается как лор (`.effect--voice`)
- [x] `titleEn` пустой не падает в кириллицу молча на английской полке — нет копирования при save, `lineInLang` без fallback, кириллица в английском поле молчит
- [x] `typeRu` / `typeEn` не принимают число («10» у Гагатыча) — `clamp_type` / `type_is_numeric`, замечание `numericType`
- [x] У расы есть имя на обоих языках (не «ШМАГ» в `nameEn`) — `prepare_race` не копирует; английская полка не печатает кириллицу как `nameEn`
- [x] Каталожное `figurineName` не подменяет `copy.title` в заголовке карты; ссылка на работу — отдельно. Подстановка `fig.name` → `titleEn` в админке снята
- [x] Creature: текст «игнор урона» / копия заклинания скрыт, пока `abilities` пуст; публиковать с текстом черты без способности нельзя
- [x] Granny: «курица считает ходы» — лор (`.effect--voice`), не правило; черты с текстом без способности — блок
