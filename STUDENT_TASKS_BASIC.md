# Блок 5. Box — «положи на кучу / спрячь за трейт»

## Задача 5.1 — Зачем вообще Box

```rust
// Рекурсивный тип НЕ компилируется без Box — у него бесконечный размер:
enum Step {
    Done,
    Next(Box<Step>), // без Box: "recursive type has infinite size"
}
```

**Сделай:**
1. Убери `Box`, прочитай ошибку, верни обратно.
2. Объясни простыми словами: почему `Box` чинит «бесконечный размер»? (Подсказка: `Box` — это указатель фиксированного размера на кучу.)

## Задача 5.2 — Box<dyn Trait> для разных «уведомителей»

Это мостик к трейтам. Хотим список разных способов уведомления в одном `Vec`.

```rust
trait Notifier {
    fn send(&self, msg: &str);
}

struct EmailNotifier;
struct LogNotifier;

impl Notifier for EmailNotifier {
    fn send(&self, msg: &str) { println!("EMAIL: {}", msg); }
}
impl Notifier for LogNotifier {
    fn send(&self, msg: &str) { println!("LOG: {}", msg); }
}

fn main() {
    let notifiers: Vec<Box<dyn Notifier>> = vec![
        Box::new(EmailNotifier),
        Box::new(LogNotifier),
    ];
    for n in &notifiers {
        n.send("Свеча зажжена");
    }
}
```

**Сделай:**
1. Запусти. Добавь третий тип `TelegramNotifier`.
2. Объясни: почему нельзя написать просто `Vec<dyn Notifier>` без `Box`? (Подсказка: размер `dyn` неизвестен на этапе компиляции, `Box` даёт фиксированный размер.)

**Объясни:** почему `Box<dyn Notifier>` удобнее, чем enum со всеми вариантами, когда типов много?
