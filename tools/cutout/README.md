# Вырезать фигурки

Программа убирает фон с фотографий фигурок: фигурка остаётся, всё остальное исчезает.

## Как пользоваться

1. На рабочем столе дважды щёлкните значок **«Вырезать фигурки»**. Откроется страница в браузере.
2. Перетащите на неё папку с фото или нажмите **«Выбрать папку…»**.
   Можно и просто бросить папку на сам значок — она откроется уже выбранной.
   Или скопируйте фото (в Finder, в браузере, скриншот) и нажмите **⌘V** на странице;
   вставлять можно по одному — фото добавляются к уже вставленным. Вставленный путь к папке тоже понимает.
3. Выберите кнопками, что нужно: фон (прозрачный, пергамент сайта, белый), файл (PNG или лёгкий WebP для сайта),
   обрезать ли по фигурке. Программа запоминает выбор.
4. Нажмите **«Начать»**. Видно, сколько готово и сколько осталось; готовые фото появляются по мере работы.
   Окно можно закрыть — работа продолжится, а когда закончится, придёт уведомление.
5. Откройте вкладку **«Посмотреть»** — там фото, где что-то могло пойти не так (чаще всего осталась рука).
   Нажмите на фото:
   - **щелчок** по руке или лишнему — убрать;
   - **Shift + щелчок** — вернуть то, что убралось зря (кота, метлу);
   - **Z** — отменить, **A** — всё хорошо, следующее.
6. **«Открыть в Finder»** — папка с готовыми картинками. Оригиналы не меняются.

Готовые картинки лежат рядом с исходной папкой, в папке с припиской `-cutout`
(для папки `фото` — `фото-cutout`). Если фото перетащили в окно, их копия и результат лягут
в «Изображения → Вырезанные фигурки». Вставленные через ⌘V — туда же.

Любую обработанную папку можно снова открыть из списка **«Недавние»** на первой странице, а там:
- **«Другие настройки…»** — пересобрать её с другим фоном, форматом или обрезкой (за секунды, без нового вырезания);
- **«Продолжить»** — если работу остановили, доделать остальное.

Программа выключается сама через 10 минут после того, как окно закрыто и работы нет.

## Если значка на рабочем столе нет

Один раз в Терминале:

```bash
~/Projects/Rita/gotiga/tools/cutout/cutout --install
```

При самом первом запуске программа минуту-две устанавливает нужное (придёт уведомление),
а при первой обработке скачивает модель (≈1 ГБ). Потом всё запускается за секунды.

## Что программа делает сама

- Подпапки обрабатываются, их структура сохраняется в результате.
- Понимает JPG, PNG, HEIC/HEIF с iPhone, WebP, TIFF, BMP, AVIF; учитывает поворот снимка.
- Цвета переводятся в sRGB, поэтому «Пергамент сайта» совпадает с цветом сайта точно.
- С краёв волос снимается цвет старого фона (иначе на светлых прядях серая кайма).
- Мелкие крошки фона убираются.
- Уже готовое не делается второй раз: повторный запуск продолжает с места.
- Испорченный файл пропускается и называется словами; остальные обрабатываются.
- Если в одной папке `кот.jpg` и `кот.png`, результаты получат имена `кот-jpg.png` и `кот-png.png`.
- Положить результат в папку с оригиналами программа не даст.

## Качество

| Кнопка | Время на фото | Когда |
|---|---|---|
| **Лучшее** | ≈10 с | по умолчанию; держит отдельные пряди и тонкие черенки мётел |
| **Быстрее** | ≈7 с | чаще сама убирает руку, но может потерять тонкое — черенок метлы, волоски |
| **Черновик** | ≈1,5 с | прикинуть; края мутнее, рука чаще остаётся |

Замер на 48 фото архива: «Лучшее» вырезает чисто сразу около 80% фото, рука остаётся примерно на каждом
десятом — она убирается одним щелчком.

## Пометки «посмотреть»

- **край кадра** — фигура касается края фото: почти всегда это рука, которая держит фигурку;
- **несколько частей** — кроме фигурки вырезано что-то отдельное (куры, метла, кот): нужно ли оно;
- **коллаж** — фото склеено из нескольких кадров (рамкой с Alt можно оставить один);
- **мало / почти всё** — похоже, промах.

Это порядок просмотра, а не приговор: на крупном плане фигурка и должна касаться края.

## Для терминала

То же самое без окна — для пакетной обработки:

```bash
tools/cutout/cutout ~/Desktop/фото --format webp --bg "#f8f1e7" --crop
```

`tools/cutout/cutout --help` — все параметры. `cutout review ПАПКА-cutout` открывает готовую папку в окне.
Пока папка открыта в окне, обработать её же в терминале нельзя (программа скажет об этом) — иначе две программы
затёрли бы журнал друг друга.

## Как устроено

| Файл | Что |
|---|---|
| `cutout` | запускалка: окружение в `.venv`, ставит зависимости при первом запуске и при правке `requirements.txt` |
| `cutout.py` | командная строка, создание значка (`--install`) |
| `app.py` + `app.html` | окно программы: локальный сервер на 127.0.0.1 (наружу не виден) и страница |
| `batch.py` | что вырезать и куда, проход по файлам (общий для окна и терминала) |
| `desk.py` | правка щелчком: маски, отмена, превью |
| `engine.py` | модель, очистка края, проверки, сборка файла |
| `store.py` | журнал папки результата и замок «одна папка — один процесс» |
| `icon.icns` | значок программы |

В папке результата лежит скрытая `.cutout/` — журнал и маски. Её не стоит удалять, если папку ещё будут
править или пересобирать; на готовые картинки она не влияет. Настройки и список недавних — в `~/.cutout/`.

Вырезает [BiRefNet](https://github.com/ZhengPeng7/BiRefNet) через [rembg](https://github.com/danielgatis/rembg)
(обе MIT), щелчок — [Segment Anything](https://github.com/facebookresearch/segment-anything) (Apache 2.0),
очистка края — [PyMatting](https://github.com/pymatting/pymatting) (MIT). Всё считается на процессоре этого Mac;
ускоритель CoreML пробовали — он собирает модель дольше 15 минут.
