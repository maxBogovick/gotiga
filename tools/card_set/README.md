# Набор карт: перенос на сервер

Папка `deploy/card-set/` (её собирает панель или `export_package.py`): 22 готовые
картинки карт с медалями (`images/`), картинки анимаций (`motion-images/`), все
данные (`cards.json`) и загрузчик `load.py`. Загрузчик использует только
стандартный Python и `curl`. Ключей в папке нет.

Набор: 6 рас (Люди, Гномы, Ведьмы, Маги, Нежить, Водяные) с таблицей урона по
кругу, 22 карты, 9 анимаций движений.

## Через панель (основной путь)

`./deploy/start.sh` → карточка **«Карты · набор для боёв на сервер»**. Сервер берётся
из поля PUBLIC_URL, ключ из ADMIN_API_KEY.

1. «Собрать пакет из локальной базы» нужна, только когда набор изменился (новые
   карты, правки чисел, новые картинки).
2. «Проверить сервер» ничего не пишет.
3. «Залить карты на сервер» (спрашивает подтверждение) и сразу после него проверка.
4. Кнопки SQL печатают запросы для базы сервера: до заливки, после и откат.

Перед заливкой сервер должен быть обновлён до нужной версии кода («Накатить тег»).

## Из терминала

```bash
python3 deploy/card-set/load.py --base https://ritunia.com/api/v1 --dry-run   # ничего не пишет
ADMIN_KEY='ключ' python3 deploy/card-set/load.py --base https://ritunia.com/api/v1
python3 deploy/card-set/load.py --base https://ritunia.com/api/v1 --verify    # всё ли на месте
python3 deploy/card-set/load.py --sql check|after|rollback                    # SQL для базы сервера
```

Повторять безопасно: что уже есть (по слагу), пропускается, набор движений
сливается по id, таблицу урона рас перезаписывают только у рас, созданных в этом
запуске (`--reset-race-damage` перезапишет у всех). Ничего не удаляется.

## Как изменить набор

- Данные карт: `tools/card_set/cards.py` (названия, показатели, способности, расы).
- Правка чисел на уже залитом сервере: `tools/card_set/tune.py`.
- Баланс замером: `src-tauri/server/examples/set_balance.rs`
  (`cargo run --release --example set_balance -- cards.json 20000`).
- После правок: «Собрать пакет», затем заливка. Новые карты добавятся, а правки
  существующих на сервере делаются через `tune.py` или админку.

## Откат

`load.py --sql rollback` печатает SQL, который удаляет только карты и расы этого
набора. Анимации в откат не входят: они безвредны.
