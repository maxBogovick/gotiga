# Лекции по Rust на бэкенде Gotiga

Самодостаточные конспекты: прочитал лекцию → понял тему → решил соответствующий блок задач
из `../STUDENT_TASKS_BASIC.md`. Каждая лекция содержит теорию, ментальную модель, разобранные
примеры, типичные ошибки компилятора, лучшие практики и разбор задач блока.

## Порядок чтения

Рекомендуемый порядок — он же порядок нарастания сложности; темы опираются друг на друга.

| № | Лекция | Тема | Блок задач |
|---|--------|------|-----------|
| 1 | [01_CRUD.md](01_CRUD.md) | CRUD, слои, sqlx, `Result`/`?`, обработка ошибок | Блок 1 |
| 2 | [02_MOVE.md](02_MOVE.md) | Владение, move, `Copy`, стек/куча | Блок 2 |
| 3 | [03_BORROW_CHECKER.md](03_BORROW_CHECKER.md) | Ссылки `&`/`&mut`, правила заимствования, NLL | Блок 3 |
| 4 | [04_LIFETIME.md](04_LIFETIME.md) | Время жизни ссылок, `'a`, элизия, структуры со ссылками | Блок 4 |
| 5 | [05_BOX.md](05_BOX.md) | `Box<T>`, рекурсивные типы, `Box<dyn Trait>` | Блок 5 |
| 6 | [06_TRAITS.md](06_TRAITS.md) | Трейты, `impl Trait`, `From`/`Into`, `derive` | Блок 6 |

## Как темы связаны

```
Владение (л.2 move)
   └─► Заимствование (л.3 borrow checker)   — отдать насовсем vs дать посмотреть
          └─► Время жизни (л.4 lifetime)     — как долго ссылка валидна
Box (л.5)  ──► Трейты (л.6)                  — Box<dyn Trait> = трейт-объект
CRUD (л.1) — практический контекст, где всё это применяется на реальном бэкенде
```

## Совет студенту
Не просто читай код примеров — **набирай и запускай** их сам, специально ломай (убери `&`, убери `Box`,
переставь строки) и читай ошибку компилятора. В Rust ошибка компилятора — это и есть половина учебника.
На защите от тебя ждут не «работает», а «я понимаю, какую ошибку этот инструмент предотвращает».
